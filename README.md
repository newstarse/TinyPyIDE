TinyPyIDE
=========

简短说明
--------
TinyPyIDE 是一个轻量级的 Python 编辑与运行集成环境（Windows），基于 ScintillaNET 提供编辑器功能，并内置伪终端用于运行 Python 程序。目标是为学习与小型开发提供快速、简洁的编辑体验。

主要功能
--------
- 语法高亮（Python）
- 智能补全（关键字、内置函数、类/对象成员补全）
- 点号（.）触发的成员补全（对常见字面量与简单赋值做类型推断）
- 内置伪终端，直接在 IDE 中运行 Python 脚本
- 支持拖放打开 .py 文件
- 最近打开文件菜单
- 单实例运行：双击 .py 文件时会唤醒已运行实例并打开文件
- 保存/另存为、查找/替换、行号、代码缩进智能处理等常用编辑功能

系统要求
--------
- Windows 10/11
- .NET 10 运行时 / SDK
- Visual Studio 2022/2026（用于源码构建和调试）
- Python（系统可执行路径中可用，用于运行脚本）

快速开始（从源码）
------------------
1. 克隆仓库：

   git clone https://github.com/newstarse/TinyPyIDE.git

2. 使用 Visual Studio 打开解决方案：

   TinyPyIDE\TinyPyIDE.slnx

3. 构建并运行：

   - 使用 Visual Studio：选择 Debug/Release，按 F5 或 使用菜单运行。
   - 命令行（可选）：使用 dotnet CLI 构建（需 .NET SDK）：
	 dotnet build
	 dotnet run --project TinyPyIDE

4. 运行后：可以通过菜单打开或拖放 .py 文件，使用底部伪终端运行脚本。

使用说明（常用场景）
-----------------
- 打开文件：文件 → 打开，或把 .py 文件拖入窗口，或双击系统中的 .py 文件（若已将本程序设置为默认打开程序，会通知运行的实例打开文件）。
- 编辑与保存：进行代码修改后可保存（会在标签页标题显示 * 表示未保存）。
- 运行脚本：在编辑器点击运行按钮或菜单项，会自动保存（若有改动），并在下方终端运行当前文件。
- 终端：内置伪终端可执行 python，并显示输出；支持停止与重启解释器。
- 自动补全：输入时会显示关键字/内置函数补全；输入 "." 时会触发对象成员补全，对常见字面量（字符串、列表、元组、集合、字典）和简单赋值推断类型以生成成员列表。

开发与调试
---------
- 代码位置：核心编辑器实现位于 ScintillaEditor.cs；成员补全逻辑封装在 CompletMember.cs；主窗口逻辑在 Form1.cs，程序入口在 Program.cs。
- 运行前请确保 Lexilla 动态库位于 runtimes\win-x64\native（如果需要语法高亮支持）。
- 若更改代码后编译失败，可能是正在运行的 TinyPyIDE.exe 占用输出文件，先结束运行进程再重试构建。
